## 目的
今の準備は 7 ステップあって多い。Git の初心者でも、ダウンロードしてボタンを押すだけで使い始められるようにする。

## ゴール（Windows は 4 ステップにする）
1. Releases ページから `peers-Sync-windows.exe` を 1 つダウンロードする（ログイン不要、展開不要）
2. ダブルクリックする（初回だけ「詳細情報 → 実行」）
3. Git がなければ、アプリの「必要なものを自動で入れる」を押す
4. 「GitHub でログイン」を押す → そのまま最初の同期が自動で始まる

Mac は 1 回だけ、Apple のインストール画面で「インストール」とパスワード入力が必要（なくせない）。

## やらないこと
- コード署名（お金がかかるので、初回の特別な開き方は残す）
- Linux での自動インストール（案内の文章だけ出す）

## 作り方の候補（Approaches）
| 案 | 内容 | 判断 |
|---|---|---|
| A（採用） | 足りないものを、アプリが OS 標準の方法で入れる（Windows：winget。Mac：xcode-select と公式の配布ファイル） | 配るファイルが小さいまま。Git は OS に普通に入るので、ほかのアプリからも使える |
| B | Git をアプリの中に丸ごと入れる | 配るファイルが大きくなる。Mac のログイン部品（GCM）は結局入れる必要がある |
| C | Git を使わない（Python だけで Git を再現する） | Git LFS とログインの部分が作れないので除外 |

## 決めたこと（すべて Claude の判断）
1. **Releases で配る**：`v*` のタグを付けると、build ワークフローが GitHub Release を作り、次の 3 つを置く。公開リポジトリなので、ログインせずにダウンロードできる。
   - `peers-Sync-windows.exe`（1 ファイル版）
   - `peers-Sync-mac-apple-silicon.zip`
   - `peers-Sync-mac-intel.zip`
2. **足りないものを自動で入れる**：起動時に git / git-lfs / Git Credential Manager があるか調べる。足りなければ、大きなボタンが「🛠 必要なものを自動で入れる」になる。
   - Windows：`winget install --id Git.Git`（Git for Windows には LFS とログインの部品も入っている）。winget がなければ、ダウンロードページを開く。
   - Mac：git がなければ `xcode-select --install`（Apple の画面が出る）。git-lfs は公式の配布ファイルをアプリが自分でダウンロードして、アプリ専用のフォルダに置く。GCM は公式の `.pkg` をダウンロードして開く（Apple のインストーラが出る）。
   - 入れ終わったら、もう一度調べて、ボタンを元に戻す。
3. **ダウンロード済みのリポジトリを自動で探す**：置き場所にまだないリポジトリは、よくある場所の 1 段下を探す。
   - 探す場所：`~/Documents/GitHub`（GitHub Desktop の場所）、`~/GitHub`、`~/source/repos`、`~/Desktop`、`~/Documents`、`~/Projects`
   - 中身が Git で、origin が同じリポジトリのものなら、それを使って `repo_paths` に覚える。
4. **ログインしたら、そのまま最初の同期を始める**。
5. README の準備の章を、新しい 4 ステップに書きかえる。

## 安全のための約束（元の設計書と同じ）
- 探して見つけたフォルダも、origin が同じときだけ使う（別のリポジトリは使わない）。
- インストールに失敗しても、アプリは落ちずに日本語で理由を出す。
