# peers Sync

**ボタン 1 つで、GitHub にある自分のリポジトリを全部、このパソコンと同期するアプリ**です。

パソコン A で作業 →「ぜんぶ同期」→ パソコン B で「ぜんぶ同期」で、B に A の作業がそのまま出てきます。
新しいパソコンでも、ログインしてボタンを押すだけで全リポジトリがそろいます。

対応：Windows / Mac（Apple シリコン）/ Mac（Intel）

---

## 1. 最初に入れておくもの

| パソコン | 入れるもの |
|---|---|
| Windows | [Git for Windows](https://git-scm.com/download/win)（インストールするだけで、Git LFS とログイン機能もいっしょに入ります） |
| Mac | ターミナルで `brew install git git-lfs` と `brew install --cask git-credential-manager` |

## 2. アプリのダウンロード

1. GitHub のこのリポジトリを開いて、上の **Actions** タブ → **build** を開きます。
2. いちばん新しい実行を開いて、下の **Artifacts** から自分のパソコン用をダウンロードします。
   - `peers-Sync-windows`
   - `peers-Sync-mac-apple-silicon`（M1・M2・M3・M4 などの Mac）
   - `peers-Sync-mac-intel`（Intel の Mac）
3. zip を開いて、中のアプリを好きな場所に置きます。

## 3. はじめて開くとき（署名なしのアプリなので 1 回だけ必要）

- **Mac**：アプリを **右クリック →「開く」** → もう一度「開く」。
- **Windows**：「Windows によって PC が保護されました」と出たら、**「詳細情報」→「実行」**。

2 回目からは、普通にダブルクリックで開けます。

## 4. 使い方

1. **「🔑 GitHub でログイン」** を押すと、ブラウザが開きます。GitHub にログインしてください。
2. **「🔄 ぜんぶ同期」** を押します。全リポジトリで、次のことを自動でやります。
   - このパソコンにないリポジトリを **ダウンロード**（クローン）
   - 変更を **セーブ**（コミット）して GitHub に **送る**（プッシュ）
   - ほかのパソコンでの変更を **取り込む**（プル）
3. リポジトリは、`C:\Users\<名前>\GitHub\`（Mac は `~/GitHub/`）に並びます。場所は「設定」で変えられます。

### 結果の見方

| 表示 | 意味 |
|---|---|
| ✅ セーブして送信 (3) | 3 個のファイルを GitHub に送りました |
| ✅ 最新を取り込み (5) | ほかのパソコンでの変更を 5 回分取り込みました |
| ⬇️ 新しくダウンロード | このパソコンになかったので、ダウンロードしました |
| ➖ 変更なし | もう同じ状態でした |
| ⚠️ 競合あり → 確認する | 同じファイルが 2 か所で変えられています（下を見てください） |
| ⏭ 同期しない設定 | 設定で外したリポジトリです |
| ❌ エラー | 理由が日本語で出ます。「くわしいログ」に Git のコマンドも出ます |

### 「⚠️ 競合あり」が出たら

その行を **ダブルクリック** すると、「このパソコンの版」と「GitHub の版」が並んで出ます。残すほうを選んで「決定」を押してください。

**選ばなかったほうも消えません。** `README (GitHub の版).md` のような名前のコピーで残ります。
画像や動画の競合は、自動で両方残します。

## 5. 送らないファイル・注意

- `.env`、`*.key`、`*.pem`、`id_rsa` など、**パスワードや鍵っぽいファイルは送りません**（警告が出ます）。
- 1 回で **20 個以上のファイルが消えていたら**、本当に消していいか確認します。
- 動画（`.mp4` `.mov` など）と 50MB を超えるファイルは **Git LFS** で送ります。
  - GitHub の無料枠は **容量 10GB・ダウンロード月 10GB・1 ファイル 2GB まで**。
  - 2GB を超えるファイルは送れないので、同期から外して警告します。
- アプリは `git push --force` などの、作業を消すおそれのある操作は **絶対にしません**。

## 6. Git の用語ミニ辞典

| 用語 | 意味 | たとえ |
|---|---|---|
| リポジトリ | 1 つのプロジェクトのフォルダと、その変更の記録 | 1 冊のノート |
| コミット | 今の状態をメモ付きでセーブする | 手紙を書いて封筒に入れる |
| プッシュ | セーブしたものを GitHub に送る | ポストに出す |
| フェッチ | GitHub に新しいものがあるか確認して取ってくる | 郵便受けを見に行く |
| プル | 取ってきて、手元に反映する（フェッチ＋マージ） | 手紙を開けて読む |
| マージ | 2 つの変更を合体させる | 2 人のメモを 1 枚にまとめる |
| 競合 | 同じ場所が 2 か所で別々に変えられて、自動で合体できない状態 | 同じ行に違うことが書かれている |
| ブランチ | 本番を汚さずに作業するための、枝分かれした下書き | 下書き用のノート |
| クローン | GitHub のリポジトリを、まるごとダウンロードする | ノートをコピーして持ち帰る |
| LFS | 動画など大きいファイル専用の置き場 | 大きい荷物は宅配便で送る |

## 開発する人向け

```bash
python -m venv .venv
.venv/bin/pip install -e .[dev]
.venv/bin/python -m pytest          # Linux で画面のテストもするなら: xvfb-run -a .venv/bin/python -m pytest
.venv/bin/python -m peers_sync      # アプリを起動
```
